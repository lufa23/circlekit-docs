This reference documents the Weather API from the [Quickstart](/quickstart):
one endpoint, `GET /forecast`, priced at $0.01 per request. It shows what any
endpoint protected by circlekit sends and expects, so you can use it as a model
for your own.

## Base URL

The endpoint runs on your machine:

```text
http://localhost:8000
```

Start it with `uvicorn server:app --port 8000` as described in the Quickstart.
The reference pages describe the server; they cannot reach a server that is not
running.

## The two responses

| Request | Response |
|---------|----------|
| No `PAYMENT-SIGNATURE` header | `402` with the payment options in the body and in the `PAYMENT-REQUIRED` header |
| Valid, funded `PAYMENT-SIGNATURE` | `200` with the content and a `PAYMENT-RESPONSE` receipt header |
| Rejected `PAYMENT-SIGNATURE` | `402` with `{"error": "..."}` |

See [Payment headers](/api/authentication) for how the headers are built and
read.
