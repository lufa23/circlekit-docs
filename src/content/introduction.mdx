circlekit is a Python SDK for [x402](https://github.com/coinbase/x402), the HTTP
payment protocol, with Circle Gateway as the payment backend. It lets you put a
price on an API endpoint and lets a program, such as an AI agent, pay that price
in USDC without a human in the loop.

The source is at
[`vyperlang/circle-titanoboa-sdk`](https://github.com/vyperlang/circle-titanoboa-sdk),
and you install it from GitHub. The package is `circle-titanoboa-sdk` and you import
`circlekit`.

## How a payment works

x402 reuses the HTTP status code `402 Payment Required`:

1. A client calls a paid endpoint with no payment.
2. The server answers `402` and describes the price, the network, and who to pay
   in a `PAYMENT-REQUIRED` header.
3. The client signs a payment authorization and repeats the request with a
   `PAYMENT-SIGNATURE` header.
4. The server asks Circle Gateway to verify and settle the payment, then returns
   the content with `200`.

Circle Gateway batches these payments, so the buyer does not pay gas per request.
The buyer deposits USDC into Gateway once and spends from that balance.

## Who these docs are for

You are a Python developer who wants to:

- charge per request for an API, for example one that AI agents call, or
- write a client or agent that pays for x402-protected APIs.

You need Python 3.10 or later and basic familiarity with FastAPI or another web
framework. You do not need prior blockchain experience. Everything here runs on
Arc Testnet with free test USDC.

## What you will build

- **[Quickstart](/quickstart)**: run a paid endpoint on your machine and read its
